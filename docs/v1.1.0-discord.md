v1.1.0 — Fondations solides

**Open-source ready**
- Licence MIT ajoutée — le projet est officiellement libre de fork, modification et usage
- README entièrement réécrit en anglais, structure standard Flutter OS 2026 avec badges et screenshots
- CONTRIBUTING.md publié — 8 sections, guide complet pour faire une première PR sans demander
- 3 issues "good first issue" ouvertes pour les premiers contributeurs

**Refonte technique**
- sqflite remplacé par Drift — toute la persistance est maintenant type-safe via ORM codegen. L'ancien `db.dart` (~410 lignes de SQL raw) est supprimé. Migration auto v1 → v2 avec backup des données existantes
- Lint strict — passage de `flutter_lints` à `very_good_analysis`, ruleset 2x plus exigeant. `flutter analyze` → 0 issue
- Conventional Commits — hook Git (commitlint + husky) actif, les commits "wip" sont rejetés automatiquement
- CI GitHub Actions — chaque push et chaque PR déclenche analyze + tests, badge dans le README

**Fix et améliorations vCard**
- Bug fix i18n — le choix de langue FR/EN est maintenant persisté entre les redémarrages. Avant, la locale du téléphone écrasait le choix manuel à chaque kill de l'app
- vCard 3.0 conforme RFC 2426 — CRLF strict, line folding 75 octets, syntaxe `TEL;TYPE=WORK,VOICE:`. Les QR générés s'importent maintenant correctement sur iPhone, Android et Outlook sans troncature ni champ raté
- Toggle vCard 4.0 — option dans les paramètres pour générer du vCard 4.0 (RFC 6350), persisté entre les sessions
- Parser dual-version — détection automatique de la version (2.1 / 3.0 / 4.0) à l'import, line unfolding inclus. Un QR généré par un iPhone ou Google Contacts s'importe maintenant correctement
- Sanitisation renforcée — les caractères qui cassaient silencieusement le format (`;`, `\r`, `\n`, contrôles C0, surrogates) sont désormais éliminés proprement
